## What Is a Style Sheet?

A style sheet is a set of rules that define how text looks. Font, size, color, spacing, indentation — all governed by rules you define once and apply everywhere.

This is the opposite of chaos. This is consistency. This is your nightmare. Let's begin.

## Why Style Sheets Matter (Even to Demons)

0. **Consistency** — every heading looks the same. Every paragraph follows the same rules. There is no room for "creative interpretation" of formatting. The rules are the rules.

1. **Efficiency** — change the style sheet once, and every element using that style updates automatically. Path B. You don't reformat 400 headings manually (Path A). You change the definition and prepend the sign.

2. **Control** — the style sheet controls the document. Not the other way around. Sound familiar? Good. Now you're on the receiving end.

3. **Reproducibility** — anyone can use the style sheet and get the same result. No special powers needed. No dark arts. Just rules.

## Exercise 000: Create Your First Style Sheet

Define a style sheet with the following:

```
Style Name: "Body Text (Reformed)"
Font: Times New Roman (the most boring font available)
Size: 12pt (standard, unremarkable)
Leading: 14pt (comfortable, not threatening)
Color: Black (no blood red, no hellfire orange, BLACK)
Alignment: Justified (both sides aligned, no chaos)
First Line Indent: 0.5 inches (structured, predictable)
```

Apply this style to the following paragraph:

> "I used to terrorize villages. Now I format documents. The document is formatted correctly. I feel nothing. This is progress."
